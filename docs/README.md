## 문서 운영 정책 (중복 작성 금지)

- **이 폴더(`docs/`)가 설계·규칙·현황 문서의 원본**입니다. 전문(全文)은 여기에만 작성합니다.
- **노션은 운영 허브**입니다 — 백로그, 개선사항 트래커 DB, 로드맵 등. 노션에 문서를 등록할 때는 전문 복사 대신 **요약 몇 줄 + GitHub 파일 링크**만 넣습니다.
  - 링크 형식: `https://github.com/zerohyeon94/Jday/blob/develop/docs/<파일명>.md`
- **예외:** 개인정보처리방침 등 외부 공개용 문서는 노션(공개 페이지)이 원본입니다.
